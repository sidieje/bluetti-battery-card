Visual editor harness

Replays the parts of Home Assistant's ha-form that the card editor depends on (getValue nesting, field elements reused by index, the value-changed merge that wraps a named section's value under its name, and lit's "only commit a bound property when it changed" rule), so the editor can be driven and asserted without a running Home Assistant. The same scenario runs headless: node test/editor-node-test.mjs.
